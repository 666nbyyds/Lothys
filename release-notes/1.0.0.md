## Lothys 1.0.0 · 第一个正式版

从这个版本开始，Lothys 不只是聊天，而是一个能替你动手做事的 Agent。

### 🤖 Agent：项目模式
- 侧边栏顶部切到「项目」，新建或选择一个手机文件夹作为项目，让 AI 直接读写文件、执行命令
- 三种执行通道自动选择：**Root**、**Shizuku**、**内置 Linux**（不需要 Root，约 4MB，可安装 Python、Node、Git 等）
- 自带终端页，可以自己敲命令；长任务放到后台运行，切出 App 也不会中断
- 修改性操作会请你批准（允许一次 / 本会话 / 总是），危险命令无论如何都会被拦截

### 📱 操作手机
- 开启「Lothys 手机操作」（设置 → Agent → 手机操作）后，AI 可以读屏、点击、滑动、输入、按键、打开应用、读通知
- 支持图片的模型会看截图操作，截图上标好了元素编号，点得更准
- **灵动岛**：AI 操作时屏幕顶部显示当前步骤，四周有渐变光晕
  - 「接管」：暂停 AI，自己操作，点「交还」继续
  - 「停止」：随时结束
  - 需要批准时直接在岛上允许 / 拒绝，不用切回 Lothys
  - 点开岛可以看 AI 的回复并直接接着说
- 三档权限：每步询问 / 仅高风险询问（默认）/ 完全权限
- 付款、转账、删除等操作，以及在支付 / 银行类应用里，默认都会请你亲自确认

### 💬 聊天体验
- **上下文圆环**：输入框里显示当前对话占用的上下文，快满时变色；可以一键压缩，也能设置自动压缩
- 回答时自动跟随到底部，手动上滑即暂停
- 新增「实时显示思考过程」「显示速度与耗时」（设置 → 常规 → 对话）
- 去掉了点赞 / 点踩按钮

### 📥 安装
下载下方的 `Lothys-1.0.0.apk` 覆盖安装即可（Android 8.0+），或在 App 内直接更新。
