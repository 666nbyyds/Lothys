## Lothys 0.7.0 内测版

### ✨ 新功能
- **不登录也能用**：打开 App 直接使用，登录变成可选（设置 → 账号里随时登录）
- **App 内更新**：有新版本时会弹窗提示，点"立即更新"直接下载安装，不用再到处找安装包
- **公告**：重要消息会在 App 里直接通知
- **提问卡片更稳定**：AI 向你提问（选项卡片）改为真正的工具调用，不会再偶尔识别不到

### 🛠 优化
- 设置页从子页面返回时，会停在原来的位置，不再跳回顶部
- 新增"匿名使用统计"开关（设置 → 数据管理），只统计版本和机型，不含聊天内容

### 🔜 即将到来
**Agent 能力正在开发中**：执行命令、读写文件、操作手机，支持 Root 与 Shizuku。敬请期待！

### 📥 安装
下载下方的 `Lothys-0.7.0.apk` 覆盖安装即可（Android 8.0+）。之后的版本可以直接在 App 内更新。
